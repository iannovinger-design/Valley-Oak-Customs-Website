Before you install

Keep your normal shop setup in place

  • Create a Design Manager backup first.
  • Close Design Manager before installing.
  • Install the RC directly over your existing Design Manager version.
  • Your existing license and library information should remain intact.
  • Do not clean up or reorganize your CNC folders before testing.
  • Use the same real library you normally work with.

Direct upgrade paths from supported Design Manager 1.x releases have been validated.

What’s new

Follow the files that make a job

Related Files

Follow a Design through its SheetCam JOB and G-code Program, or start from any of those files and work backward.

Review and save matches

Use Needs Review, All Workflow Files, Saved Relationships, and Workflow History to confirm what belongs together.

Built for real shop libraries

Relate one Design to several JOBs, several Designs to one mixed sheet, or multiple machine files to one JOB.

Find files quickly

Search in Choose Related File, compare modified dates, sort useful columns, and include workflow-only search locations.

Control folder behavior

Choose what appears in the design library separately from where Design Manager searches for related files.

Improved Shared Workspace

Use the same Related Files workflow across participating shop PCs with the existing safety and authority protections.

First-time setup

Set up Related Files after upgrading

This tells Design Manager where it may search for related JOB, TAP, and NC files.

  1. 1
    Open Settings.
  2. 2
    Open Workflow.
  3. 3
    Choose Set up folder visibility and search.
  4. 4
    Review the confirmation and choose OK.
  5. 5
    Click Refresh related files.
  6. 6
    Allow the first scan to finish.

Large libraries may take a little while during the first scan.

What to test

Use your real shop library

The most useful test is your everyday library exactly as it is now.

Especially useful files

  • Old or messy folders
  • SVG and DXF files
  • SheetCam JOB files
  • TAP and NC files
  • Files spread across several folders
  • Designs reused across multiple JOBs
  • Mixed sheets with several Designs
  • Old TAP/NC files stored in root folders

Things to try

  • Confirm correct suggestions
  • Choose Not related for incorrect suggestions
  • Browse All Workflow Files
  • Review Saved Relationships
  • Open View related files
  • Use Choose related file manually
  • Try sorting, filtering, and modified-date clues
  • Look for old files you forgot about

Important safety note

Design Manager does not execute TAP or NC machine programs.

Machine files may be inspected, related, or shown in File Explorer, but machine execution remains outside Design Manager.
