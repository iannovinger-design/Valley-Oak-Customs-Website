Before you install

Keep your public version in place

  • This build is intended only for the three invited private beta testers.
  • Close Design Manager before installing the Preview.
  • Download the ZIP and extract it to a normal folder.
  • Run Valley_Oak_Design_Manager_v1.5_Preview_Setup_1.5.0-preview.1.exe.
  • Read and accept the Private Beta Agreement during setup.
  • Launch Valley Oak Design Manager — v1.5 Preview from the Start menu.

The Preview installs separately and does not replace the current public v1.4.x application.

What to test

Try your normal design workflow

The most useful feedback is whether the Preview makes it easier to understand a design and the files used to manufacture it.

Find a design

Browse, search, filter, and select designs the way you normally work.

Open Design Workspace

Check whether the preview, design information, and manufacturing files are clear.

Follow related files

Review the Design → SheetCam JOB → TAP/NC hierarchy and any direct machine-file relationships.

Preview and Reveal

Try the Preview and Reveal actions on related JOB, TAP, and NC files.

Use two PCs

If you use Shared Workspace, check whether connected, offline, and read-only states make sense.

Report confusion

Tell us about anything unexpected, unclear, missing, or harder than your current workflow.

Machine-file safety

Always verify a machine file before cutting.

A confirmed relationship, successful preview, Production Ready status, or available file does not prove that a TAP or NC file is safe to cut. Verify the material, dimensions, tooling, post processor, origin, consumables, and machine setup before use.

Rollback

Remove the Preview without removing v1.4

  1. 1
    Close the Preview.
  2. 2
    Open Windows Settings → Apps → Installed apps.
  3. 3
    Uninstall Valley Oak Design Manager — v1.5 Preview 1.5.0-preview.1.
  4. 4
    Choose whether to remove only the Preview's separate local profile.

Uninstalling the Preview does not remove the public Design Manager application, CNC design files, public licensing state, or a Shared Workspace.

This private Preview may contain unfinished behavior and may be replaced before the public v1.5 release.
