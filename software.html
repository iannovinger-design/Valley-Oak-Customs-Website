Valley Oak Design Manager

Find it. Organize it. Open it. Make it.

Current stable v1.3.0 Windows 10/11 · 64-bit

Valley Oak Design Manager is a Valley Oak Customs product built around real CNC plasma and small-shop workflows. It gives SVG and DXF libraries a visual, searchable home while leaving the original design files where you put them.

  • See and find the library. Browse native SVG and DXF previews, then search by tags, notes, status, collections, favorites, and recent files.
  • Follow your CNC workflow. Workflow History shows Design Manager activity and file changes first noticed across your shop PCs, without claiming who edited the file.
  • Keep related files together. Link SheetCam JOB and .tap/.nc G-code files to a design, open them quickly, and check timestamps for possible workflow mismatches. JOB previews remain browsable in the main library.
  • Share organization between two PCs. Create, connect to, or migrate into a Shared Workspace for shared tags, notes, favorites, collections, status, and organization.
  • Manage shop PCs simply. A Workspace Administrator manages shared settings and connected PCs while Members keep doing normal work. Designate a recovery PC in case the Administrator is replaced or unavailable.
  • Keep working safely. If the shared folder is unavailable, the last complete view stays visible in read-only mode until the connection is validated again.
  • Back up and return safely. Create verified Shared Workspace backups, return to the previous Local Workspace, or convert Shared metadata into a new Local Workspace.
  • Tag more consistently. Controlled Tags improves suggestions and reuse while preserving deliberate spelling and historical tags.
  • Open supported designs in LightBurn. Send an SVG or DXF to the locally installed LightBurn application without changing the original design file.
  • Exclude folders without deleting anything. Hide selected Local Workspace child folders from normal Design Manager views, then include them again later with saved organization intact.

Upgrading from v1.2? Install v1.3.0 over the current installation. Your Local library setup, saved organization, licensing, and Local exclusions stay in place. Older Shared Workspaces may need an upgrade; Design Manager creates a verified backup first. Update every PC using that workspace to v1.3.
