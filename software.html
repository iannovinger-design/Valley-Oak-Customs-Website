Valley Oak Design Manager

Find it. Organize it. Open it. Make it.

Current stable V1.0.0 Windows 10/11 · 64-bit

Stop hunting through folders and cryptic filenames. Design Manager gives SVG and DXF libraries a visual, searchable home while leaving the original design files where you put them.

  • See the library. Native SVG and DXF previews make designs recognizable at a glance.
  • Find work fast. Search, tags, notes, status, collections, favorites, and recent files.
  • Clean up safely. Locate duplicates without modifying original design files.
  • Build better proofs. Preview Studio adds material, background, shadow, branding, and export controls.
  • Match the shop. Store shop and material settings with the workflow.
  • Stay local-first. Your design library and working data remain on your Windows PC.
